# news-JS (TypeScript)

News reader on top of [News API](https://newsapi.org/), migrated from JavaScript to strict TypeScript.

## Run

- Copy `.env.example` to `.env` and set your values
  (for development without spending API quota use `API_URL=https://rss-news-api.onrender.com/mocks/`)
- `npm install`
- `npm start` - dev server
- `npm run build` - production build to `dist`
- `npm run lint` / `npm run typecheck`
